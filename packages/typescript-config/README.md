## 🧩 @repo/typescript-config

Reusable TypeScript configuration presets to simplify project setup.  
Includes base configs for:

- TypeScript libraries
- Next.js
- React.js
- Remix
- Vite

Use it to avoid repeating boilerplate in each package.

## 📦 Installation

```bash
pnpm add @repo/typescript-config --filter api
```
