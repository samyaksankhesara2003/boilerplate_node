# 🌐 @repo/i18n

Centralized internationalization (i18n) package for managing response messages in multiple languages.

Currently supports:

- 🇬🇧 English (`en.json`)
- 🇫🇷 French (`fr.json`)

All message keys defined in **response-handler/constants/response-messages** file
**must be also added** in **i18n** package

---

## 📦 Installation

```bash
pnpm add @repo/i18n --filter api
```
